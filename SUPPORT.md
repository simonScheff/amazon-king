# Support

amazon-king is community-supported alpha software. Use GitHub Discussions for
setup and usage questions and GitHub Issues for reproducible bugs and scoped
feature requests. Security issues must follow [SECURITY.md](SECURITY.md).

Maintainers do not provide guaranteed response times, campaign-management
advice, Amazon Ads API approval, or recovery of lost advertiser data. Operators
are responsible for their infrastructure, backups, Amazon agreements, and ad
spend. Keep writes disabled until the instance has been validated against an
Amazon test account or a dedicated low-risk campaign.
