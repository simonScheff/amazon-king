# Governance

amazon-king is currently a maintainer-led project. Maintainers set the roadmap,
review contributions, make releases, and have final responsibility for safety-
critical decisions.

Substantial changes to Amazon write behavior, authentication, encryption,
optimizer rules, data retention, or the public API should begin with an issue
describing the problem, alternatives, risks, and migration plan. Routine bug
fixes and documentation improvements can proceed directly to a pull request.

As the contributor base grows, maintainership may be extended to contributors
with a sustained record of sound technical judgment, respectful collaboration,
and attention to advertiser safety. Governance changes will be proposed and
reviewed publicly.
